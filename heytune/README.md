# HeyTune app snapshot

This directory (`heytune/`) holds the app snapshot (OuterTune `lite`,
local-playback only) plus the HeyTune voice integration (Whistle STT +
Needle function calling). See the project README at
[`../README.md`](../README.md) for what HeyTune is and how to build it.

Upstream: [OuterTune/OuterTune](https://github.com/OuterTune/OuterTune)
(GPL-3.0, see [`LICENSE`](LICENSE)). Files here keep their original
copyright headers. The old OuterTune README was removed: it describes
the discontinued upstream project, not HeyTune.
